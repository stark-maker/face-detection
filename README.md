# 实时人脸检测（OpenCV）

## 项目简介
基于 Python + OpenCV 的摄像头实时人脸检测，能实时框选人脸、显示 FPS、截图保存。

## 功能
- 摄像头实时视频流
- Haar 级联人脸检测
- 实时显示 FPS 与检测数量
- 按 s 截图、按 q 退出

## 环境
- macOS / Python 3.10+
- OpenCV (pip install opencv-python)

## 运行
python3 face_detect.py
